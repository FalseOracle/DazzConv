
# DazzConv

DazzConv — это десктопный веб комбайн для работы с медиафайлами. Он создан, чтобы закрывать рутинные задачи без танцев с бубном, установки десятка разных программ или мутных сайтов.

Всем знакома ситуация, когда нужно срочно сжать файл для отправки, перегнать пачку старых фото в WebP для сайта, сделай ICO для приложения, сохранить плейлист с YouTube или выдернуть аудиодорожку из подкаста. DazzConv объединяет всё это в одном окне, работая локально, быстро и без навязчивой рекламы, все на своих мощностях.

## Что умеет программа

### Конвертация медиа
Поддерживаются все актуальные форматы. Вы можете использовать готовые пресеты или гибко настраивать параметры (битрейт, частоту кадров, разрешение, кодеки). С обновлениями количество форматов будет увеличиваться.
* **Видео:** MP4, MKV, AVI, MOV, WebM. Поддержка современных кодеков H.264, H.265 (HEVC) и VP9.
* **Аудио:** MP3, WAV, FLAC, OGG, AAC, OPUS, M4A.
* **Изображения:** JPG, PNG, WebP, AVIF, BMP, TIFF, ICO, HEIC. Есть пакетное изменение размера и контроль качества сжатия.

### Пакетная обработка
Вам не нужно конвертировать файлы по одному. Можно выбрать целую папку с сотнями картинок, видео или аудио, применить ко всем единые настройки и идти заниматься своими делами. Программа сама выстроит файлы в очередь и обработает их в фоновом режиме.

### Встроенный загрузчик видео
На базе `yt-dlp` (https://github.com/yt-dlp/yt-dlp) программа умеет скачивать контент с YouTube, TikTok, Twitter/X, Reddit, VK и еще почти двух тысяч сайтов. 
* Можно скачать видео в максимальном доступном качестве или выбрать конкретное разрешение.
* Поддержка скачивания только аудиодорожки (удобно для музыки и подкастов).
* Работа с плейлистами и каналами.

### Производительность и сетевые возможности
* **Аппаратное ускорение:** Если в системе есть видеокарта NVIDIA, можно включить кодировщик NVENC. Это колоссально экономит время и ресурсы процессора при рендере тяжелого видео. Работает при одиночном рендере.
* **Поддержка прокси:** Встроена работа через SOCKS5, HTTP и HTTPS. Полезно, если нужно скачать что-то с зарубежного ресурса, где прямой доступ ограничен или работает нестабильно.

### Интерфейс
Никакого перегруза функционалом. Интерфейс чистый и с полноценной темной темой. Всё на своих местах, ничего не отвлекает от задачи.

## На чем написано

Проект использует современный стек Microsoft, а под капотом работают проверенные временем open-source решения, чтобы не изобретать велосипеды там, где это не нужно:

* **.NET 8 MAUI + Blazor** — кроссплатформенный UI и бизнес-логика. Blazor позволяет писать интерфейс на C# и Razor, сохраняя высокую скорость отклика.
* **FFmpeg** — тяжелая артиллерия для обработки аудио и видео.
* **ImageMagick** — мощный движок для конвертации и манипуляций с изображениями.
* **yt-dlp** — лучший на сегодняшний день инструмент для скачивания видео из сети.

## Установка и системные требования

Готовые сборки можно скачать в разделе [Releases](../../releases/latest).

**Минимальные требования:**
* **ОС:** Windows 10/11 (x64) или macOS 11+ (Apple Silicon / Intel).
* **Память:** от 4 ГБ ОЗУ (для пакетной обработки тяжелых видео рекомендуется 8 ГБ и выше).
* **Место на диске:** ~150 МБ для самой программы + место для временных файлов при конвертации.

> **Примечание:** При первом запуске программа может попросить разрешение на скачивание актуальных бинарников `yt-dlp`, `ffmpeg` и `imagemagick`. Это делается один раз, чтобы не тащить тяжелые зависимости в дистрибутив и всегда иметь свежие версии парсеров.

## Сборка из исходного кода

Если вы хотите собрать проект самостоятельно или внести свой вклад:

1. Убедитесь, что у вас установлен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и workload для MAUI.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/FalseOracle/DazzConv.git
   cd DazzConv
   ```
3. Восстановите зависимости и запустите проект:
   ```bash
   dotnet restore
   dotnet build
   dotnet run
   ```
