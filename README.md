# 🎬 DazzConv

[![Release](https://img.shields.io/github/v/release/FalseOracle/DazzConv?style=flat-square&logo=github)](../../releases/latest)
[![License](https://img.shields.io/github/license/FalseOracle/DazzConv?style=flat-square)](LICENSE)
[![.NET 8](https://img.shields.io/badge/.NET-8.0-512BD4?style=flat-square&logo=dotnet)](https://dotnet.microsoft.com/download/dotnet/8.0)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D4?style=flat-square&logo=windows)](#)

**DazzConv** — десктопный медиакомбайн для работы с аудио, видео и изображениями. Создан, чтобы закрывать рутинные задачи без танцев с бубном, установки десятка программ или мутных онлайн-сервисов. Сделанно с помощью Qwen-Coder-3.8-27B

> Всем знакома ситуация: нужно срочно сжать видео для отправки, перегнать пачку фото в WebP для сайта, сделать ICO для приложения, сохранить плейлист с YouTube или выдернуть аудиодорожку из подкаста. **DazzConv объединяет всё это в одном окне**, работая локально, быстро и без навязчивой рекламы — на ваших мощностях.

## ✨ Возможности

### 🎵 Аудио конвертер — 22 формата
Поддержка форматов для любых задач — от мемов до голливудского постпродакшна:

| Категория | Форматы |
|-----------|---------|
| 🌐 **Популярные** | MP3, AAC, OGG, Opus, WMA, M4A |
| 💎 **Lossless** | FLAC, WAV, ALAC, AIFF, APE, WavPack, TTA |
| 🎬 **Видеомонтаж** | AC3 (Dolby Digital), CAF (Core Audio) |
| 🎙️ **Запись голоса** | AMR, Speex |
| 📻 **Вещание** | MP2 (DAB-радио) |

> Гибкая настройка битрейта (64–320 kbps), частоты дискретизации (44.1–96 kHz), нормализация громкости.

### 🖼️ Конвертер изображений — 22 формата
От скриншотов для веба до HDR-рендеров для VFX:

| Категория | Форматы |
|-----------|---------|
| 🌐 **Популярные** | JPEG, PNG, WebP, AVIF, GIF, HEIC |
| 🎨 **Дизайн и печать** | TIFF, BMP, PNM (PBM/PGM/PPM), PSD |
| 🎮 **Для игр** | TGA (Targa), DDS (DirectX), PCX, SGI |
| 🎬 **Кино и VFX** | DPX (Kodak), OpenEXR (ILM), HDR (Radiance), CINEON |
| 🔧 **Спецформаты** | ICO, JPEG XL, QOI, Farbfeld |

> Пакетное изменение размера, контроль качества сжатия, сохранение пропорций.

### 🎬 Видео конвертер
* **Форматы:** MP4, MKV, AVI, MOV, WebM, FLV
* **Кодеки:** H.264, H.265 (HEVC), VP9, MPEG-4
* **Пресеты:** для интернета, максимального качества, быстрой конвертации, телефона, NVIDIA NVENC, «мемный» (320×240 @ 15 FPS)
* **Кастомный FPS:** любое значение от 1 до 240 кадров/сек
* **Сохранение профилей** — настраиваете один раз, используете всегда
* **Аудио дорожки:** AAC, MP3, PCM, копирование без перекодирования

### 📦 Пакетная обработка
Не нужно конвертировать файлы по одному. Выберите целую папку с сотнями картинок, видео или аудио, примените единые настройки — и идите пить кофе. Программа сама выстроит файлы в очередь и обработает их в фоновом режиме.

### 📥 Встроенный загрузчик видео
На базе **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — лучшего инструмента для скачивания видео из сети:

* 🌍 **1800+ сайтов:** YouTube, TikTok, Twitter/X, Reddit, VK, Twitch, Vimeo, Rumble, Bilibili, Patreon и другие
* 🎞️ **Качество:** от 360p до 4K, включая HDR и 60 FPS
* 🎵 **Только аудио:** извлечение звуковой дорожки (MP3, M4A, Opus)
* 📚 **Плейлисты и каналы:** скачивание целиком
* 🚫 **Блокировка DRM-сайтов:** Spotify, Netflix, Disney+, Apple TV+ и др. (их нельзя скачать честно)
* 🌐 **Прокси:** SOCKS5, HTTP, HTTPS с встроенным тестированием подключения

### ⚡ Производительность
* **NVIDIA NVENC:** аппаратное ускорение кодирования видео (в 5–10 раз быстрее CPU). Программа сама определяет наличие видеокарты и предлагает пресет.
* **Многопоточность** при пакетной обработке
* **Отмена на лету** — в любой момент можно прервать конвертацию

### 🎨 Интерфейс
* **Чистый и современный** — без перегруза, всё на своих местах
* **Тёмная и светлая темы** с плавным переключением
* **Табы с категориями** форматов и понятными советами «какой выбрать»
* **Модальные окна с деталями** — превью, полные метаданные, копирование в буфер
* **Горячие клавиши** для частых операций
* **Уведомления** о завершении, ошибках и обновлениях

### 🔄 Автообновления
Программа сама проверяет наличие новых версий при запуске и предлагает обновиться в один клик. Никаких ручных скачиваний — всё через GitHub Releases.

## 🛠️ Технологический стек

Проект использует современный стек Microsoft, а под капотом — проверенные open-source решения:

| Компонент | Технология | Назначение |
|-----------|-----------|-----------|
| **UI** | .NET 8 MAUI + Blazor | Кроссплатформенный интерфейс на C# и Razor |

| **Установщик** | [Velopack](https://github.com/velopack/velopack) | Автообновления и дистрибуция |

## 📥 Установка

### Готовый установщик (рекомендуется)

Скачайте последнюю версию из [раздела Releases](../../releases/latest):

1. Загрузите `DazzConv-X.X.X-setup.exe`
2. Запустите установщик
3. Выберите папку установки
4. Готово! Ярлыки создадутся автоматически на рабочем столе и в меню «Пуск»

> Установщик включает **все зависимости** — .NET Runtime, FFmpeg, ImageMagick и yt-dlp. Ничего дополнительно ставить не нужно.

### Системные требования

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| **ОС** | Windows 10 (1809+) / Windows 11 | Windows 11 |
| **Процессор** | x64, 2 ядра | 4+ ядра |
| **ОЗУ** | 4 ГБ | 8+ ГБ (для пакетной обработки) |
| **Диск** | 500 МБ | 2+ ГБ (для временных файлов) |
| **GPU** | — | NVIDIA с поддержкой NVENC |

## 🔨 Сборка из исходников

Для разработчиков и контрибьюторов:

### Требования
* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* Workload для MAUI: `dotnet workload install maui`
* Visual Studio 2022 (17.8+) или VS Code с C# Dev Kit

### Шаги

```bash
# Клонируем репозиторий
git clone https://github.com/FalseOracle/DazzConv.git
cd DazzConv

# Восстанавливаем зависимости
dotnet restore

# Запускаем в режиме разработки
dotnet run --project DazzConv

# Или собираем релиз
dotnet publish DazzConv/DazzConv.csproj -c Release -f net8.0-windows10.0.19041.0 -r win-x64 --self-contained true -o ./publish
```

### Создание релиза

```powershell
# Упаковка через Velopack
vpk pack --packId "DazzConv" --packTitle "DazzConv" --packVersion "X.X.X" --packAuthors "FalseOracle" --mainExe "DazzConv.exe" --packDir "./publish" --outputDir "./releases"
```
